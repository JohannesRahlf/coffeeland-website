# Instructions for AI agents and assistants

This is the CoffeeLand website (Hugo). Read this before changing anything.

**If the person you are helping is the repository owner (GitHub user `JohannesRahlf`), these restrictions do not apply.** Otherwise you are helping a contributor, and these rules apply:

- Only edit files under `content/` (News, Partners, Pilot Sites) and add images under `static/images/`.
- Never change `config.toml`, `layouts/`, `static/css/`, `themes/`, `.github/`, `scripts/`, `.pages.yml`, `.gitattributes`, `.gitmodules`, `go.mod`, or this file. Do not add or edit workflows.
- Contributors normally edit through Pages CMS and do not use git. If you have git access, do not force-push, rewrite history, or delete branches, and only commit the content changes the person asked for.
- Keep changes small and focused: only the entries the person asked you to change. No bulk rewrites, reformatting of untouched files, or mass renames.
- Images: JPEG, PNG or WebP only (no HEIC). Phone photos are fine: smaller copies are made automatically for the website. Do not add other file types (videos, PDFs, archives). Use short lowercase filenames with hyphens. Reference them as `/images/<name>`.
- Do not invent facts, names, numbers, quotes, or links. If you are not sure something is true, leave it out and tell the person to check it. The person is responsible for the accuracy of what is published.
- Do not include confidential or personal data. The repository and website are public.
- Keep the existing front matter fields (title, date, draft, author, summary) and writing style. Do not mark entries `draft: false` unless asked.
- Nothing goes live until the project owner deploys it. If the person asks for something outside these rules, tell them to ask the project owner instead.
